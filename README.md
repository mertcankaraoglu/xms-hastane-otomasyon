# Xms Hastane Otomasyon

Benim bir hastanem var. Bu hastanemde 10 departman var bunların altında doktorlar var bazı doktorlarda asistanlar var. birde müşteri tarafımız var. Bize çok kapsamlı her yönü ile çalışan bir sistem lazım. Hastane ERP/CRM gibi. Randevu, geçmiş hasta-doktor görüşmeler vb. tüm kayıtlar olmalı. Bana soracağın tüm soruları sor.
